# Project Docs

This directory is the durable knowledge base for the project.

Start here:

1. `CURRENT.md` - current product and project truth.
2. `product/` - product requirements, scope, and roadmap.
3. `design/` - information architecture, user flows, and UI principles.
4. `engineering/` - architecture, data model, and Tauri boundaries.
5. `plans/` - active and completed execution plans.
6. `decisions/` - decision records for choices that should not be rediscovered.
