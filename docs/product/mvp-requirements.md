# Desktop Job Application Manager MVP

## Problem Frame

First-time job seekers and junior career switchers need a private, structured way to find job postings, manage active hiring processes, keep application files organized, and avoid missing deadlines.

The MVP should behave like a local desktop workspace for job applications, not a general productivity planner or AI career coach.

## MVP Scope

1. Job discovery and target company management.
2. Active hiring process management.
3. Application material file management with version tracking.
4. App and desktop notifications.

## Explicit Non-Goals

- AI analysis or writing assistance.
- Automatic job posting tracking.
- Automatic job posting parsing.
- Automatic application form filling.
- Cloud sync or backup.
- Mobile app.
- Kanban board view.
- Daily task planning.
- Weekly planning.
