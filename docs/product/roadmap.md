# Roadmap

## MVP

- Local-only desktop app.
- Job discovery through an in-app browser.
- Target company list.
- Active hiring process list.
- Application material and submission version management.
- App and OS notifications.

## Later

- Optional cloud backup.
- Mobile companion app.
- Target company job posting change detection.
- Job posting format parsing.
- User profile-based application form prefill.
- New job alerting.
- Automatic preparation card creation from tracked postings.
