# Information Architecture

## Primary Sections

1. Discovery
   - Explore job postings through an in-app browser.
   - Save the current page as a job posting.
   - Manage target companies and careers page URLs.

2. Processes
   - Manage active job postings and hiring stages.
   - Store posting URL, company, role, deadline, next event, linked materials, and notes.

3. Materials
   - Manage resumes, cover letters, portfolios, certificates, links, and submitted versions.
   - Support both linked files and app-managed copies.

4. Alerts
   - Show deadline and hiring process notifications.
   - Later versions can schedule desktop notifications from local data.

## Removed From MVP

- Kanban board view.
- Daily planning.
- Weekly planning.
- AI-assisted writing or analysis.
