# 0001. Desktop-First Local-Only MVP

## Status

Accepted

## Context

The target users are first-time job seekers and junior career switchers. They may be sensitive about uploading resumes, cover letters, portfolios, certificates, and submission files to a remote service.

The app also needs to work well with files, job posting pages, desktop notifications, and application-specific local workflows.

## Decision

Build the MVP as a desktop-first app with local-only storage.

The MVP will not require accounts, cloud sync, remote storage, or AI features.

## Consequences

- The MVP can lead with privacy and user trust.
- The initial scope avoids authentication, cloud storage, sync conflict handling, and privacy policy complexity.
- Later versions can add optional cloud backup and mobile companion features.
