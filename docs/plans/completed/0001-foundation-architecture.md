# 0001. Foundation Architecture

## Goal

Create a lightweight frontend architecture for the desktop-first job application manager MVP.

## Scope

- Replace the default Tauri example screen with an app shell.
- Add domain folders for jobs, companies, materials, and alerts.
- Add shared product types and typed mock data.
- Add the first architecture and information architecture docs.
- Keep persistence, file management, browser integration, and notifications as future implementation work.

## Status

Completed

## Result

- Default Tauri example UI was replaced with a domain-oriented app shell.
- Frontend folders now separate application composition, product features, shared code, and Tauri boundaries.
- Typed mock data establishes the first product model without introducing persistence yet.
- Architecture and information architecture docs were added for future work.
